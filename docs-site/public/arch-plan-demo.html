The <arch-plan> element

One <script type="module" src="https://archlang.uk/arch-plan.js"> tag, then one element per drawing. Each plan below is compiled in this browser. How to use it: Embed a floor plan in a web page.

From a URL: src="/examples/studio.arch"

Written inline

plan "Garden studio" { units mm wall exterior thickness 200 { (0,0) (5000,0) (5000,3600) (0,3600) close } room id=r_studio at (0,0) size 5000x3600 label "Studio" uses living door at (2500,3600) width 900 wall exterior hinge left swing in window at (2500,0) width 2000 wall exterior window at (5000,1800) width 1200 wall exterior }

plan "Broken" { room id=r at (0,0) size }
